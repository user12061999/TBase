# Contributing

The foundation source is in Packages/com.studio.foundation. See the [package contributor guide](Packages/com.studio.foundation/CONTRIBUTING.md) for assembly boundaries, tests and review requirements.

A root .gitignore is supplied; review the selected source diff before staging.
